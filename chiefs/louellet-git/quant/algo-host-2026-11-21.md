# Where the algo engine runs (study, 2026-11-21)

The person asked this head to study where `fa algo run` (a paper engine: live Alpaca quotes, fills in our own
simulator, no orders, decisions in seconds, 9:30 to 16:00 New York each market day) should run. Sources were read on
2026-11-21 by a research agent. "est." marks an estimate with no source.

## Facts
- Alpaca runs on Google Cloud us-east4 (N. Virginia), with fiber to Secaucus, NJ (docs.alpaca.markets/docs/alpaca-api-platform).
- Free plan: 200 REST calls a minute; a stream of 30 equity symbols (IEX) and 200 option quotes (indicative, not OPRA);
  one stream connection for each key: two engines on one key collide (docs.alpaca.markets/docs/streaming-market-data).
- Claude Code cloud: a background command lasts 2 hours at most; an idle VM pauses and can be reclaimed; scheduled
  tasks run at most each hour, each in a fresh session (code.claude.com/docs/en/cloud-environments, /routines).
- GitHub Actions: a job lasts 6 hours at most; a schedule can be late or dropped; a private repo costs about $32 to
  $38 a month for this use; the terms allow use "to develop and test your application(s)" (a grey area here).
- Windows laptop: Task Scheduler can wake it (WakeToRun), but on battery Modern Standby can drop Wi-Fi, Windows 11
  24H2 can disable wake sources, and Windows Update can restart it (learn.microsoft.com, modern-standby-wake-sources).
- Small VM in US East: AWS Lightsail N. Virginia $5/month (0.5 GB); DigitalOcean NYC $4/month (512 MiB); Google
  e2-micro free in us-east1 only; Oracle free VMs can be reclaimed when idle. Latency to Alpaca about 1 to 5 ms (est.),
  against 10 to 60 ms (est.) from a home connection.

## Comparison
| Place | Cost a month | Reliability in market hours | Upkeep | Journal back to git |
|---|---|---|---|---|
| Laptop | $0 | weak (sleep, Wi-Fi, updates) | low | push at 16:05 by hand or task |
| VM in US East | $4 to $5 | high | setup 1 to 2 h; patches; keys on a server | cron push with a deploy key |
| GitHub Actions | about $35 (private) | schedule can be late or dropped | two chained jobs | easy |
| Claude Code cloud | usage | not possible for 6.5 h | none | easy |
| Raspberry Pi | $85+ once | home power and internet | medium | cron push |

## Recommendation
1. Monday 2026-11-23: the first live run on the person's laptop (no cost, no account), with the engine logging each
   gap and resuming after a restart. It shows that the engine works live.
2. For the daily paper runs that a decision can use: a $4 to $5 VM in US East (Lightsail N. Virginia or DigitalOcean
   NYC), set up by the Head of Technology, with a deploy key that pushes only the journal and its own Alpaca key (or
   one engine for the two persons). A laptop gap biases a paper result; the VM removes most gaps for $5 a month.
Main risks: laptop: missed sessions; VM: upkeep and the keys on a public server.
