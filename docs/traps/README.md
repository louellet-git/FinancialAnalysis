# Traps (one file for each new trap)

A new trap is a new file in this folder: `<YYYY-MM-DD>-<short-name>.md`. Two branches that each
add a trap then add two files, and git merges them with no conflict.

Form of a file: a title (the trap in one line), then *Trap:* what goes wrong, *What to do:*,
and *Evidence:* (a file and a function, or a command). ASD-STE100 Simplified Technical English.

The traps before 2026-11-21 are in `docs/HIDDEN-ASSUMPTIONS.md`. Read both. Correct an old trap in
that file; add a new trap here.
