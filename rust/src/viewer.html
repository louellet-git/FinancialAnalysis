FinancialAnalysis Viewer

This page runs on your computer. It shows analysis only. It does not send orders to a broker.

Stock look-up

Type a ticker. The page shows the standard input variables from the SEC data, the check status and the findings. A ticker that is not in the cache needs the SEC and the variable SEC_USER_AGENT.

Monte Carlo DCF

Select a ticker with a driver model and type the market price. The engine runs the simulations and gives the value range for each share. The result is a model result. Do not use it alone for a trade.

Company report

One report for a ticker: price and valuation, fundamentals, Monte Carlo DCF panels, the driver model and the options market. The program makes the file with python -m scripts.visualize_dcf. The first report takes some seconds. The program saves the file in data/reports. It makes the file again only when you ask. The driver model section exists only for a ticker with analysis/<TICKER>/driver_model.py. The ticker needs saved company data (python -m scripts.import_financials TICKER).

Treasury curves

Par yields of the latest day. The real curve is the TIPS curve.

Overnight rates

NY Fed reference rates.

Inflation

Breakeven inflation, the 5y5y forward, the real 10Y yield and CPI. CPI comes from the BLS.

Corporate bonds

ICE BofA index for each rating, Moody's seasoned yields and the Treasury HQM corporate spot curve. The data comes from FRED.

Option bots: leaderboard

The text of trading/research/LEADERBOARD.md. All option prices in the backtest are model prices. To run the bots again, use fa trade backtest.
