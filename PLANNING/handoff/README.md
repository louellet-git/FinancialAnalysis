# Per-person handoff

Related: open work is the board (`PLANNING/board/`).

1. Input: your session state. Output: `PLANNING/handoff/<first name>.md`, lowercase
   (`luc.md`); naming and write rules: `docs/COLLABORATION.md` §Board, handoff and decisions.
2. Delete items as completed; delete the file when empty.
3. Error: if an edit conflicts or the state is unclear, ask the owner before writing.
