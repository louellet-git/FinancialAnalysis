Report from the Head of Fundamental Research (FA-L), 2026-11-20, from a full sync in a new machine
(`fa sync --tickers-file F --only sec,prices,gsw`, 1,114 tickers): Yahoo answers HTTP 429, and the log
line "yahoo answered HTTP 429; waiting 0 s before one new try" comes again for each ticker. The speed was
about 16 tickers each minute.

`docs/DATA-SOURCES.md`, rule 3, says that a source that answers HTTP 429 stops for the run. Examined on
2026-11-20, not fully traced: the price pass (`rust/src/market/price_cache.rs`, the two blocks with
`Attempt::RateLimited`) stops a source for one call only. The sync starts one call for each ticker, so
the stop is lost when the subsequent source (Nasdaq) gives the prices. The stop of the full run is in
`rust/src/hostnet.rs` (`block`, `blocked`); `rust/src/sync/runner.rs` uses it for the other hosts.

Correction: when a price source answers 429 in a sync run, stop that host for the run (`hostnet::block`),
and do not try a host that is stopped. Do not get around the limit.
