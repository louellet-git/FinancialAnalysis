The Cboe page www.cboe.com/delayed_quotes/spx/quote_table/ says it is "strictly prohibited to
download delayed quote table data ... by using auto-extraction programs" and that Cboe blocks IP
addresses (found by the Head of Quant Research, 2026-11-21). Quality and Risk confirmed the stop.
The Cboe chain copies already in the private store stay; no new copy is added.

Done on the branch (2026-11-21): `fa options snapshot` uses Alpaca by default and refuses
`--source cboe` before any key, network or cache step; `fa analyze` reads today's snapshot or takes an
Alpaca one; the `options` data set of `fa sync` is Alpaca only; `fa trade paper` refuses a live chain
(use `--no-live`) until an Alpaca chain adapter exists (Head of Quant Research); the Cboe delayed-quote
client and its parser are removed; a scan test finds no Cboe delayed-quote address in the option-chain
code. Not in this ticket: the Cboe VX settlement, VX history and VIX history files (other Cboe pages:
www.cboe.com/us/futures/market_statistics/settlement/csv, cdn.cboe.com/data/us/futures/...,
cdn.cboe.com/api/global/us_indices/daily_prices/VIX_History.csv); their terms need a decision.
